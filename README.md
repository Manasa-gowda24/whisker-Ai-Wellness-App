# 🐱 Whiskers – AI Wellness Companion

> A Generative AI-powered wellness companion built with Amazon PartyRock.

## 🌸 About Whiskers

Whiskers is an AI-powered wellness application designed to provide personalized wellness guidance based on user-provided concerns and current cycle information.

The application combines user inputs with Generative AI to create a personalized wellness experience.

## ✨ Key Features

- 🌸 Current cycle phase input
- 📝 Symptoms and concerns input
- 🤖 Personalized AI wellness guidance
- 📅 Daily wellness routine
- 💡 Interactive Generative AI experience

## 🔄 How It Works

**User Input → AI Processing → Personalized Guidance → Daily Wellness Routine**

Users provide their current cycle phase and describe their symptoms or concerns. Whiskers then generates personalized wellness guidance and a daily wellness routine.

## 🛠️ Technologies Used

- ☁️ Amazon PartyRock
- 🤖 Amazon Bedrock
- 🧠 Generative AI
- ✨ Prompt Engineering
